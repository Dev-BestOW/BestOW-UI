# 스크린리더 수동 점검 체크리스트

자동 검사(axe)는 이름·역할·대비처럼 **코드로 판단할 수 있는 문제**만 찾아요. "실제로 들었을 때 이해되는가" 는 사람이 스크린리더로 써 봐야 알 수 있어서,
이 문서를 따라 점검하고 결과를 적어요. 프로덕션 권장 선언 기준 중 하나예요(ROADMAP P13-1).

## 점검 환경

최소 두 조합(★), 가능하면 네 조합 모두 해요. 같은 컴포넌트도 스크린리더마다 읽는 말이 달라서, **정확한 문구가 아니라 "의미가 전달되는지"** 를 봐요.

| | 스크린리더 | 브라우저 | 기기 |
|---|---|---|---|
| ★ | VoiceOver | Safari | macOS |
| ★ | NVDA (무료) | Chrome 또는 Firefox | Windows |
| | VoiceOver | Safari | iPhone |
| | 센스리더 | Chrome 또는 Edge | Windows (국내 공공기관에서 많이 씀) |

점검 페이지(배포된 예제 앱): [상호작용](https://dev-bestow.github.io/BestOW-UI/playground/interactive) ·
[탐색·오버레이](https://dev-bestow.github.io/BestOW-UI/playground/navigation) ·
[서버 컴포넌트](https://dev-bestow.github.io/BestOW-UI/playground/)

### 자주 쓰는 키

| 동작 | VoiceOver (macOS) | NVDA | 센스리더 |
|---|---|---|---|
| 켜기/끄기 | ⌘ + F5 | Ctrl + Alt + N | Ctrl + Alt + S (설치 설정에 따라 다름) |
| 다음 항목 읽기 | VO(Ctrl+Option) + → | ↓ (탐색 모드) | ↓ |
| 다음 제목 | VO + ⌘ + H | H | H |
| 폼 조작 모드 | 자동 | Enter 또는 NVDA + Space | Enter |
| 현재 항목 다시 읽기 | VO + F3 | NVDA + Tab | Insert + ↑ (기본 설정) |

> 마우스를 쓰지 않고 **Tab·화살표·Enter·Space·Esc** 만으로 진행해요. iPhone 은 오른쪽·왼쪽 쓸기로 이동, 두 번 탭으로 실행해요.

## 결과 적는 법

각 항목의 결과 칸에 조합별로 적어요: ✅ 기대대로 / ⚠️ 쓸 수 있지만 어색함(메모) / ❌ 이해·조작할 수 없음(메모 필수).
❌·⚠️ 는 GitHub 이슈로 올리고, 고친 뒤 `apps/storybook/stories/accessibility/componentA11y.ts`·`kwcag.ts` 의 확인 방법에 "스크린리더 수동 점검(날짜·조합)" 을 적어요.

## 1. Select (상호작용 · "플랜")

1. Tab 으로 "플랜" 에 간다 → **레이블 "플랜", 버튼/콤보 상자, 현재 값(없으면 "선택하세요")** 이 들린다.
2. Enter(또는 Space·↓)로 연다 → 목록이 열렸다는 것, 첫 항목(또는 선택된 항목)이 들린다.
3. ↓ 로 "Pro" 까지 이동 → 항목마다 이름과 선택 여부가 들린다.
4. Enter 로 고른다 → 목록이 닫히고 버튼에 포커스, **"Pro"** 가 들린다.
5. 다시 열고 Esc → 닫히고 값은 그대로.

| VO macOS | NVDA | VO iOS | 센스리더 |
|---|---|---|---|
| ✅ (2026-10-21) | ✅ (2026-10-22, Chrome) |  |  |

## 2. Combobox (상호작용 · "배송 도시")

1. Tab 으로 입력창 → **레이블, 편집 가능한 콤보 상자** 가 들린다.
2. "부" 입력 → 결과 목록이 생겼다는 것(또는 결과 개수)이 들린다.
3. ↓ 로 항목 이동 → 포커스는 입력창에 있지만 **현재 항목 "부산"** 이 들린다.
4. Enter → 입력창 값이 "부산" 이 되고 들린다. 토스트 알림이 읽힌다.
5. 없는 글자("ㅋㅋ") 입력 → **"결과가 없어요"** 가 들린다.

| VO macOS | NVDA | VO iOS | 센스리더 |
|---|---|---|---|
| ✅ (2026-10-21) — 처음엔 5 "결과가 없어요" 안 들림 → 항상 있는 status + 입력 멈춘 뒤 0.8초에 알림으로 수정, 재확인 ✅ | ✅ (2026-10-23, Chrome) |  |  |

## 4. NumberInput (상호작용 · "좌석 수")

1. Tab 으로 입력창 → **레이블 "좌석 수", 스핀 버튼(또는 숫자 입력), 현재 값 "1석"**, 가능하면 최소·최대가 들린다.
2. ↑ 두 번 → 값이 바뀔 때마다 **"2석", "3석"** 이 들린다.
3. Tab → −/+ 버튼은 건너뛰고 다음 요소로 간다(의도된 동작).

> **NVDA·센스리더에서 꼭 볼 것:** 값 문구를 따로 알리는 영역(assertive)을 2026-10-21 에 추가했어요(VoiceOver 가 "선택 항목 대치됨, 2" 로만 읽어서).
> 스핀 버튼 값을 스스로 읽는 스크린리더에서는 **"2석" 이 두 번** 들릴 수 있어요 — 그러면 ⚠️ 로 적어 주세요.

| VO macOS | NVDA | VO iOS | 센스리더 |
|---|---|---|---|
| ✅ (2026-10-21) — 처음엔 "선택 항목 대치됨, 2"(단위 없음) → 키·버튼 조작 값을 assertive 알림으로 수정, 재확인 ✅ | ✅ (2026-10-23, Chrome) — "2석" 한 번만 들림(중복 없음) |  |  |

## 5. 서식 입력 — 전화번호·금액·사업자번호 (상호작용 · 정산 정보)

1. 전화번호 입력창에 숫자 "01012345678" 입력 → 입력 중 글자가 들리고, 끝나면 **"010-1234-5678"** 로 읽힌다.
2. 금액 입력창에 "1250000" 입력 → **"1,250,000"** 과 아래 **"125만원"** 안내가 함께 들린다(설명으로).
3. 사업자번호에 잘못된 번호(예: 1234567890) 입력 → 10자리를 채우는 순간 화면에 오류가 나온다. Shift+Tab → Tab 으로 다시 들어가 **1~2초 기다리면** "올바르지 않음" 과 **오류 안내 문구** 가 들린다(VoiceOver 는 설명을 잠시 뒤에 읽는다).

| VO macOS | NVDA | VO iOS | 센스리더 |
|---|---|---|---|
| ✅ (2026-10-21) — 사업자번호 오류는 다시 들어가면 설명으로 읽힘(입력 순간엔 알림 없음 → 개선 후보) → 2026-10-23 입력 멈춘 뒤 0.8초 알림 추가, 재확인 ✅ | ✅ (2026-10-23, Chrome) |  |  |

## 6. DatePicker (상호작용 · "정산 희망일")

1. Tab 으로 입력창 → 레이블과 형식 안내가 들린다.
2. Tab 으로 "달력 열기" 버튼 → Enter → **대화상자(달력)**, 오늘(또는 선택된) 날짜에 포커스, **"15, 목요일…" 처럼 날짜·요일** 이 들린다.
3. 화살표로 날짜 이동 → 날짜마다 읽히고, 공휴일·오늘 표시가 들린다. (예제 앱 공휴일은 날짜가 고정된 것만: 10/3·10/9·12/25 등 — 공휴일은 라이브러리에 내장하지 않고 `isHoliday` 로 넘긴다)
4. Enter → 달력이 닫히고 입력창에 날짜가 들어가 들린다. Esc 로 닫으면 "달력 열기" 버튼으로 돌아온다.

| VO macOS | NVDA | VO iOS | 센스리더 |
|---|---|---|---|
| ✅ (2026-10-21) — 예제 앱에 isHoliday 가 없어 공휴일 확인 불가 → playground 에 고정 공휴일 추가 후 "9, …금요일, 공휴일" 확인 | ✅ (2026-10-23, Chrome) |  |  |

## 7. FileUpload (상호작용 · "통장 사본")

1. Tab → **그룹 "통장 사본"**, "파일 선택" 버튼과 도움말(형식·크기)이 들린다.
2. Enter → 운영체제 파일 창이 열린다. 파일 2개를 고른다 → **"파일 2개 선택됨"** 이 들린다.
3. 목록으로 이동 → 파일 이름·크기, **"○○ 삭제"** 버튼이 들린다.
4. 삭제 버튼 Enter → **"○○ 삭제됨"** 이 들리고 포커스가 다음 삭제 버튼(없으면 "파일 선택")으로 간다.
5. 형식이 다른 파일을 고르면 **거부 이유** 가 들린다.

| VO macOS | NVDA | VO iOS | 센스리더 |
|---|---|---|---|
| ✅ (2026-10-21) — 처음엔 크기(Tab 으로 못 들음)·"삭제됨"(포커스 이동과 같은 순간) 안 들림 → 삭제 버튼 설명에 크기, 알림 0.5초 뒤로 수정, 재확인 ✅ | ✅ (2026-10-23, Chrome) |  |  |

## 8. Modal (상호작용 · "삭제")

## 10. DropdownMenu (탐색·오버레이 · "문서 메뉴", "보기 옵션")

1. "문서 메뉴" 버튼 → **메뉴 버튼(팝업 있음)** 이 들린다. Enter → **메뉴**, 첫 항목 "편집" 이 들린다(단축키 "⌘E" 는 이름에 섞이지 않음).
2. ↓ 로 이동 → "공유 (권한 없음)" 은 비활성으로 들리거나 건너뛴다. "이동" 은 **하위 메뉴 있음** 이 들린다. → 로 열고 ← 로 닫힌다.
3. Esc → 닫히고 버튼으로 돌아온다.
4. "보기 옵션" 메뉴 → 체크 항목은 **체크 상태**, 라디오 항목은 **선택 상태** 가 들리고 Space 로 바뀐다.

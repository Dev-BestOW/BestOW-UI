# TanStack Table 과 함께 쓰기

BestOW 의 [Table](?path=/docs/components-table--docs)은 **그리는 일**만 해요(표 구조·정렬 버튼·선택된 행·빈 상태·접근성).
정렬·검색·페이지·선택 같은 **표 상태**는 [TanStack Table](https://tanstack.com/table) 에 맡기면, 데이터 표를 직접 키우지 않고도 관리자 화면의 목록을 만들 수 있어요.
두 라이브러리는 서로를 모르고, 아래처럼 prop 몇 개로 이어요.

<Canvas of={TanStackStories.OrdersExample} />

## 설치

```bash
npm install @bestow-ui/react @tanstack/react-table
```

TanStack Table 은 화면을 그리지 않는 headless 라이브러리라 스타일 충돌이 없어요. `@bestow-ui/react` 는 TanStack 에 의존하지 않아요.

### 정렬

```tsx
// TanStack 의 'asc' | 'desc' | false → TableHead 의 sortDirection
const toSortDirection = (sorted: false | 'asc' | 'desc'): TableHeadProps['sortDirection'] =>
  sorted === 'asc' ? 'ascending' : sorted === 'desc' ? 'descending' : 'none';

<TableHeader>
  {table.getHeaderGroups().map((group) => (
    <TableRow key={group.id}>
      {group.headers.map((header) => {
        // 정렬할 수 있는 열만 버튼이 되고 aria-sort 가 붙는다
        const sortProps = header.column.getCanSort()
          ? { sortDirection: toSortDirection(header.column.getIsSorted()), onSort: () => header.column.toggleSorting() }
          : {};
        return (
          <TableHead key={header.id} {...sortProps}>
            {flexRender(header.column.columnDef.header, header.getContext())}
          </TableHead>
        );
      })}
    </TableRow>
  ))}
</TableHeader>;
```

TanStack 은 숫자 열을 처음 누르면 **내림차순**부터 정렬해요. 다른 열처럼 오름차순부터 하려면 `useReactTable({ sortDescFirst: false })`.

### 행 선택

```tsx
column.display({
  id: 'select',
  header: ({ table }) => (
    <Checkbox
      aria-label="이 페이지 모두 선택"
      checked={table.getIsAllPageRowsSelected()}
      indeterminate={table.getIsSomePageRowsSelected()}
      onChange={table.getToggleAllPageRowsSelectedHandler()}
    />
  ),
  cell: ({ row }) => (
    <Checkbox
      aria-label={`${row.original.id} 선택`}
      checked={row.getIsSelected()}
      onChange={row.getToggleSelectedHandler()}
    />
  ),
});

useReactTable({
  // …
  getRowId: (row) => row.id, // 선택을 주문번호로 기억 — 데이터를 다시 불러와도 같은 행
});
```

TanStack 을 쓰지 않는 간단한 표라면 BestOW 의 `useTableSelection` 으로도 같은 체크박스를 만들 수 있어요([목록 화면 패턴](?path=/docs/guides-화면-패턴--docs)).

## 접근성에서 챙길 것

- **표 이름** — `<Table caption="주문 목록">`. 화면에 보이지 않게 하려면 `aria-label`.
- **정렬 상태** — `TableHead` 에 `sortDirection` 을 주면 `aria-sort` 가 붙어 스크린리더가 열 이름과 함께 정렬 상태를 읽어요. 아이콘만으로 방향을 보이지 않아요.
- **체크박스 이름** — "선택" 만 반복하지 말고 "ORD-001 선택" 처럼 행을 구분해요.
- **바뀐 결과 알리기** — 검색·페이지·선택으로 바뀐 "37건 중 1–10 · 10건 선택됨" 을 처음부터 있는 `role="status"` 영역에 넣어요. 포커스는 옮기지 않아요.
- **결과 없음** — 빈 표 대신 `TableEmpty` 안에 이유와 되돌릴 버튼(검색 지우기)을 둬요.

## 서버에서 정렬·페이지를 할 때

데이터가 많아 서버가 정렬·검색·페이지를 맡으면 TanStack 의 `manual*` 옵션을 켜고, 상태가 바뀔 때 다시 불러와요.

```tsx
const table = useReactTable({
  data: page.items, // 지금 페이지의 행만
  columns,
  rowCount: page.total, // 전체 건수 — getPageCount() 가 계산돼요
  state: { sorting, pagination },
  onSortingChange: setSorting,
  onPaginationChange: setPagination,
  manualSorting: true,
  manualPagination: true,
  getRowId: (row) => row.id, // 페이지를 넘겨도 선택이 같은 행을 가리키게(필수)
  getCoreRowModel: getCoreRowModel(),
});
// sorting·pagination 이 바뀌면 그 값으로 서버에 다시 요청한다(react-query 의 queryKey 에 넣는 식)
```

불러오는 동안에는 행 대신 `TableSkeleton` 을 그리고 표에 `aria-busy` 를 줘요.

## 알아 둘 점

- **React Compiler** 를 쓰면 `useReactTable` 을 부르는 컴포넌트는 컴파일러가 메모이즈하지 않고 건너뛰어요(TanStack Table v8 의 알려진 사항, 동작에는 문제없음).
  ESLint `react-hooks/incompatible-library` 경고가 나오면 이 이유예요.
- 긴 목록의 가상 스크롤은 `@tanstack/react-virtual` 을 함께 쓰는데, 스크린리더가 전체 행 수를 알 수 없게 되므로 꼭 필요할 때만 써요. 관리자 화면은 보통 페이지 나누기가 더 쉬워요.
- 이 예시 코드는 Storybook 의 상호작용 테스트(정렬·선택·페이지·검색·결과 없음)와 라이트·다크 접근성 검사를 매번 통과해요.

# 컴포넌트별 키보드·스크린리더

각 컴포넌트를 **키보드로 어떻게 조작하는지**, **스크린리더가 무엇을 듣는지**(역할·이름·상태),
그리고 **사용하는 쪽이 챙길 것**을 정리했어요. 항목별 근거는 [KWCAG 2.2 대응](?path=/docs/accessibility-kwcag-2-2-대응--docs) 문서에 있어요.

- 오버레이·메뉴·탭·선택처럼 Radix 위에 만든 컴포넌트는 [WAI-ARIA Authoring Practices](https://www.w3.org/WAI/ARIA/apg/patterns/)
  패턴의 키보드 동작을 그대로 따라요.
- 모든 컴포넌트는 Tab 으로 이동할 때 **포커스 링**이 보이고(마우스 클릭에는 안 보임), 포커스 링 색은 배경과 3:1 이상이에요.
- 기본 문구(닫기, 로딩 중, 이전 페이지 …)는 [LocaleProvider](?path=/docs/introduction--docs)로 바꿀 수 있어요.

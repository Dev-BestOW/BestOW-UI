# BestOW UI

**한국 서비스를 만들 때 바로 쓰는, 접근성이 검증된 React 디자인 시스템이에요.**
대표색 하나로 내 브랜드 테마를 만들고, 약관 동의부터 인증번호·주소·날짜 입력까지 한국 서비스에 늘 필요한 부품을 기본으로 써요.

- **한국 서비스 키트** — 약관 동의, 인증번호, 전화번호·사업자등록번호·금액·주소·날짜 입력 → [Korean Kit](?path=/docs/korean-kit-agreementgroup--docs)
- **검사로 증명하는 접근성** — 모든 스토리를 라이트·다크에서 axe 로 자동 검사, KWCAG 2.2 항목별 대응 근거 → [KWCAG 2.2 대응](?path=/docs/accessibility-kwcag-2-2-대응--docs)
- **대표색 하나로 끝나는 테마** — 브랜드 색을 넣어도 글자 대비·포커스 링 기준을 자동으로 지켜요 → [테마 빌더](?path=/story/foundations-theme-builder--builder)
- **가볍고 서버 컴포넌트 친화적** — 스타일은 빌드 때 정적 CSS 로 뽑혀 런타임 비용이 없고, Next.js App Router 에서 그대로 써요.
- **한국어 기본, 다국어 가능** — 기본 문구는 한국어, `LocaleProvider` 로 한 번에 바꿔요.

- **`@bestow-ui/react`** — 테마(`ThemeProvider`)와 컴포넌트
- **`@bestow-ui/icons`** — SVG 아이콘 컴포넌트 (기본 세트는 [Lucide](https://lucide.dev), ISC)
- **`@bestow-ui/tokens`** — 색상·간격·타이포그래피 등 원시 디자인 토큰

예제 앱(Next.js): [dev-bestow.github.io/BestOW-UI/playground](https://dev-bestow.github.io/BestOW-UI/playground/) ·
소스·이슈: [github.com/Dev-BestOW/BestOW-UI](https://github.com/Dev-BestOW/BestOW-UI)

## 설치

```bash
pnpm add @bestow-ui/react
# 또는 npm install @bestow-ui/react / yarn add @bestow-ui/react
```

`@bestow-ui/icons` 와 `@bestow-ui/tokens` 는 의존성으로 함께 설치돼요. React 18 이상이 필요해요.

## 설정

### 1. 스타일시트 불러오기

앱 진입점(Next.js 는 `app/layout.tsx`)에서 **한 번** 불러와요. 모든 컴포넌트 스타일이 들어 있어요.

```tsx
import '@bestow-ui/react/styles.css';
```

### 2. ThemeProvider 로 감싸기

`ThemeProvider` 는 테마 클래스와 CSS 변수를 붙인 `div` 를 렌더링해요. 앱 최상단에서 한 번 감싸 주세요.
토스트를 쓰려면 그 안쪽에 `ToastProvider` 도 둬요.

```tsx
import { ThemeProvider, ToastProvider, Button, useToast } from '@bestow-ui/react';

export function App() {
  return (
    <ThemeProvider theme="light">
      <ToastProvider>
        <SaveButton />
      </ToastProvider>
    </ThemeProvider>
  );
}

function SaveButton() {
  const { toast } = useToast();
  return <Button onClick={() => toast({ title: '저장했어요', color: 'success' })}>저장</Button>;
}
```

Next.js App Router 에서는 상태를 가진 Provider 를 `'use client'` 파일로 분리하고 `layout.tsx` 에서 감싸면 돼요.
컴포넌트 자체는 서버 컴포넌트에서도 바로 쓸 수 있어요.

```tsx
// app/providers.tsx
'use client';

import { ThemeProvider, ToastProvider } from '@bestow-ui/react';
import type { ReactNode } from 'react';

export function Providers({ children }: { children: ReactNode }) {
  return (
    <ThemeProvider theme="light" style={{ minHeight: '100vh' }}>
      <ToastProvider>{children}</ToastProvider>
    </ThemeProvider>
  );
}
```

```tsx
// app/layout.tsx
import '@bestow-ui/react/styles.css';
import { Providers } from './providers';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ko">
      <body style={{ margin: 0 }}>
        <Providers>{children}</Providers>
      </body>
    </html>
  );
}
```

## 다크 모드

`theme` 에 `'light'` 또는 `'dark'` 를 넘겨요. 상태로 들고 있다가 바꾸면 모든 컴포넌트(모달·툴팁 같은 portal 포함)가 함께 바뀌어요.

```tsx
const [mode, setMode] = useState<ThemeName>('light');

<ThemeProvider theme={mode}>
  <Button variant="ghost" onClick={() => setMode((m) => (m === 'light' ? 'dark' : 'light'))}>
    테마 전환
  </Button>
</ThemeProvider>;
```

- 중첩한 `ThemeProvider` 에서 `theme` 를 생략하면 바깥 모드를 이어받아요. 특정 영역만 다크로 보여 줄 때는 안쪽에 `theme="dark"` 를 줘요.
- 하위 컴포넌트에서 현재 모드가 필요하면 `useTheme()` 를 써요.
- 이 Storybook 도 상단 툴바의 🖌 **Theme** 메뉴로 라이트·다크를 바꿔 볼 수 있어요.

## 브랜드 테마 (커스터마이징)

대표색을 직접 골라 보며 라이트·다크 미리보기와 대비 리포트를 확인하고 코드를 복사하려면 [Foundations › Theme Builder](?path=/story/foundations-theme-builder--builder) 를 쓰세요.

대표색·모서리·글꼴 등을 프로젝트에 맞게 바꿀 수 있어요. 모드(`theme`)와 브랜드(`overrides`)는 따로 동작해서, 모드를 바꿔도 브랜드는 유지돼요.

```tsx
import { ThemeProvider, createTheme, createIntentColors } from '@bestow-ui/react';

const brand = createTheme(
  createIntentColors('primary', '#7c3aed'), // 대표색 하나로 라이트·다크 색 세트 자동 생성 (대비 4.5:1 보장)
  {
    common: { radius: { md: '6px' }, font: { family: { sans: 'Inter, sans-serif' } } }, // 라이트·다크 공통
    dark: { color: { bg: { default: '#0b0b10' } } }, // 모드별 값
  },
);

<ThemeProvider theme={mode} overrides={brand}>
  …
</ThemeProvider>;
```

ThemeProvider 없이 CSS 만으로도 바꿀 수 있어요. 변수 이름(`--bestow-*`)은 고정돼 있어요.

```css
:root {
  --bestow-color-primary-solid: #7c3aed;
  --bestow-radius-md: 6px;
}
```

- 직접 만든 portal 요소(예: `createPortal` 로 body 에 붙이는 패널)에는 `usePortalProps()` 가 돌려주는 `className`·`style` 을 붙여야 테마가 적용돼요.
- 미리보기는 [Foundations › Theming](?path=/story/foundations-theming--playground),
  변수 전체 목록은 [CSS 변수](?path=/story/foundations-theming--css-variables) 에서 볼 수 있어요.

## 문구 바꾸기 · 다국어

컴포넌트의 기본 문구("닫기", "결과가 없어요", "이전 달" 등)는 한국어예요. `LocaleProvider` 로 한곳에서 바꿀 수 있고,
영어 묶음 `en` 도 들어 있어요. 컴포넌트에 직접 준 prop 이 가장 우선해요.

```tsx
import { LocaleProvider, en } from '@bestow-ui/react';

<LocaleProvider messages={en}>…</LocaleProvider>                 // 전부 영어로
<LocaleProvider messages={{ close: '창 닫기' }}>…</LocaleProvider>  // 일부만 바꾸기
```

ThemeProvider 안에서는 한글을 단어 단위로 줄바꿈해요(`word-break: keep-all`). 띄어쓰기 없는 긴 문자열(URL 등)만 넘치지 않게 끊어요.

## 아이콘

```tsx
import { SearchIcon, TrashIcon } from '@bestow-ui/icons';

<SearchIcon />                              // 24px, 장식용 (aria-hidden)
<TrashIcon size={16} strokeWidth={1.5} />
<SearchIcon title="검색" />                  // 스크린리더가 읽는 아이콘
<Button startIcon={<PlusIcon size={16} />}>추가</Button>
```

필요한 아이콘만 import 하면 그 아이콘만 번들에 들어가요. 전체 목록은 [Foundations › Icons](?path=/story/foundations-icons--gallery) 에서 검색할 수 있어요.

## 스타일 직접 쓰기

앱 코드에서도 같은 토큰을 쓰면 다크 모드·브랜드 테마가 자동으로 따라와요.

```tsx
// vanilla-extract 를 쓰는 프로젝트
import { style } from '@vanilla-extract/css';
import { vars } from '@bestow-ui/react';

export const panel = style({ padding: vars.space[4], background: vars.color.bg.subtle, borderRadius: vars.radius.md });
```

```css
/* 일반 CSS */
.panel {
  padding: var(--bestow-space-4);
  background: var(--bestow-color-bg-subtle);
}
```

토큰 값은 [Foundations › Design Tokens](?path=/story/foundations-design-tokens--colors) 에서 볼 수 있어요.

## 접근성

- 대화형 컴포넌트는 [Radix UI](https://www.radix-ui.com) primitive 위에 만들어 키보드 조작·포커스 관리·ARIA 속성을 지원해요.
- 모든 스토리는 CI 에서 실제 브라우저로 렌더링하고, 라이트·다크 두 테마에서 axe 로 검사해요 (글자 대비 4.5:1 등).
- 폼 컴포넌트는 `label` 을 꼭 넘겨 주세요. 보이는 레이블이 없으면 `aria-label` 을 줘요.
- 애니메이션은 사용자의 "동작 줄이기(prefers-reduced-motion)" 설정을 따라요.
- 한국형 웹 콘텐츠 접근성 지침(KWCAG 2.2) 항목별로 정리한 [대응 근거](?path=/docs/accessibility-kwcag-2-2-대응--docs)를 참고하세요.
